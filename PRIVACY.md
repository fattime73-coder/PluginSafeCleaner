# Privacy

Plug-in Safe Cleaner works entirely on the local Mac.

- It does not send plug-in names, file paths, scan results, or usage data over the network.
- It does not contain analytics, advertising, accounts, or telemetry.
- Scan results remain in memory while the application is running.
- Quarantine manifests are stored locally under `~/Documents/PlugIn Safe Cleaner/Quarantine/`.
- Administrator authorization is requested by macOS only when moving items in `/Library`.

The links in the in-app rescan guide open Apple Support and Universal Audio Support in the default browser only when the user chooses them.
